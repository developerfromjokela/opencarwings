Custom Data Channel Format

Data channel information is supplied to the server as JSON. The server will send some data about the vehicle, if permissions are granted.

Request from server

Section titled “Request from server”

The vehicle sends a POST request with a JSON payload:

Request fields

Section titled “Request fields”
Field Description
lang Language code. Possible values: es, sl, cz, pl, gr, no, fi, se, dk, nl, pt, it, de, fr, ru (the example also shows en).
tz Time zone, for example "0.00".
distance_unit km or mile.
temp_unit C for Celsius, F for Fahrenheit.
lat, lon Vehicle latitude and longitude.
speed err if speed is not available, otherwise the speed in distance_unit units.
direction Heading in degrees.
car_status stop when the vehicle is in park, run when it is in D or R.

Expected response format

Section titled “Expected response format”

Respond with a JSON array of slideshow objects in this format.

Two slides maximum

Return at most 2 slides.

Slide fields

Section titled “Slide fields”
Field Required Description
title1 Yes Slide name (max 32 characters).
title2 Yes Slide description (max 128 characters).
title3 No Optional description (max 64 characters).
onscreen No On-screen readable text content, shown via the Details menu (max 1024 characters).
tts No Text for the TTS engine to read aloud. Can include XML for the TTS engine.
map_point No Map point object with lat and lon coordinates.
phone_number No Phone number in international format.
img_base64 No Base64-encoded image, max. 15,480 bytes. The format must be JPEG or PNG.
bell No When true, an announcement sound is played before the TTS content is read. Default: true.
save No When true, the slides are saved in CARWINGS memory. Default: true.
